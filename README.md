welcome to my website

to start a development server:

```sh
npm run dev

# or start the server and open the app in a new browser tab
npm run dev -- --open
```

to build it:

```sh
npm run build
```

You can preview the production build with `npm run preview`.

---

# note!!
before running the website, be sure to copy `private-example` to `private`. this creates a dummy `private` file for symlinks to work and for the website to actually work.
